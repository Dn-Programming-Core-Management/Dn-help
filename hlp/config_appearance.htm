Appearance configuration

These settings are used to configure the visual appearance of the pattern editor.

  • Color scheme
    Listbox shows option for pattern editor's color appearance called "Scheme". This is built in table of "Colors" of pattern editor.

  • Colors
    In this group you can set each part of your pattern editor's color shown below:
    • Background
      Default: ■
      This is background of pattern editor.
    • Highlighted background
      Default: ■
      This is Highlighted background of pattern editor.
    • Highlighted background 2
      Default: ■
      This is Highlighted background 2 of pattern editor.
    • Pattern text
      Default: ■
      This is Pattern text of pattern editor.
    • Highlighted pattern text
      Default: ■
      This is Highlighted pattern text of pattern editor.
    • Highlighted pattern text 2
      Default: ■
      This is Highlighted pattern 2 text of pattern editor.
    • Instrument column
      Default: ■
      This is Instrument column text of pattern editor.
    • Volume column
      Default: ■
      This is Volume column text of pattern editor.
    • Effect number column
      Default: ■
      This is Effect number column text of pattern editor.
    • Selection
      Default: ■
      This is Selection color of pattern editor.
    • Cursor
      Default: ■
      This is Cursor color of pattern editor.
    • Current row (normal mode)
      Default: ■
      This is Current row (normal mode) color of pattern editor.
    • Current row (edit mode)
      Default: ■
      This is Current row (edit mode) color of pattern editor.
    • Current row (edit mode)
      Default: ■
      This is Current row (playing) color of pattern editor.


Two toggle options are available:

  • Pattern colors
    Check this to enable individual colors for each column. When unchecked the note/octave color will be used for all columns.

  • Display flats:
    Display notes as flats (♭) instead of sharps (♯) in the pattern editor.
