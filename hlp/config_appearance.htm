Appearance configuration

These settings are used to configure the visual appearance of the pattern editor.

  • Color scheme
    Listbox shows option for pattern editor's color appearance called "Scheme". This is built in table of "Colors" of pattern editor.

  • Colors
    In this group you can set each part of your pattern editor's color shown below:
    • Background color
      • Background
        Default: #000000
      • Highlighted background
        Default: #101000
      • Highlighted background 2
        Default: #202000
    • Pattern text
      • Pattern text
        Default: #00FF00
      • Highlighted pattern text
        Default: #F0F000
      • Highlighted pattern text 2
        Default: #FFFF60
      • Instrument column
        Default: #80FF80
      • Volume column
        Default: #8080FF
      • Volume column 2
        Default: #AA3030
      • Effect number column
        Default: #FF8080
    • Cursor
      • Selection
        Default: #867DF2
      • Cursor
        Default: #808080
      • Current row (normal mode)
        Default: #3020A0
      • Current row (edit mode)
        Default: #802030
      • Current row (non-follow playing)
        Default: #500040
    • Channel headers
      • Header background
        Default: #FFFFFF
      • Header corner
        Default: #FFFFFF
      • Header text
        Default: #000000

    Two toggle options are available:

    • Pattern colors
      Check this to enable individual colors for each column. When unchecked the note/octave color will be used for all columns.

    • Display flats:
      Display notes as flats (♭) instead of sharps (♯) in the pattern editor.

    • Fade volume color:
      Check this to enable fading color behavior for volume column. You can configure what color to fade into by setting "Volume column 2" on Colors group.



  • Header font and size
    Listbox serves option for header of patterneditor's font and its size. You can check how it looks like on Preview.

  • Pattern font and size
    Listbox serves option for patterneditor's font and its size. You can check how it looks like on Preview.

  • Save / Load feature
    You can save your own colors/fonts settings to text file by clicking Save. And by Loading that saved text file, you can configure colors/fonts of your appearance settings.
